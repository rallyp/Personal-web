# Personal Web

Building and maintaining my personal website, rallypagulayan.com.

Project reference notes: @claude/site-setup.md

## Working rules

- This repo is cloned on two Macs (both Apple Silicon) at `~/Projects/Personal-web`.
  GitHub is the sync between them, not iCloud.
- Before starting work, check the repo is up to date with GitHub (Rally fetches/pulls
  in GitHub Desktop). Remind Rally to commit and push when a session's work is done,
  so the other Mac can pull it.
- Claude edits files; Rally commits and pushes in GitHub Desktop.
- The live site is not touched until Rally confirms publishing.
